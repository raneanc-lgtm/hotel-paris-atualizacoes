# Sinuca Mobile — app Android (Slim Creative)

Este ramo (`sinuca-mobile`) é só o app do jogo. Ele não mexe nos pacotes do Hotel Paris do ramo `main`.

- O jogo fica em `app/src/main/assets/index.html`.
- A cada envio para este ramo, o GitHub compila o APK sozinho (aba **Actions**) e publica em **Releases**.
- Para atualizar o jogo: troque o `index.html` e envie. Sai um APK novo que instala por cima do anterior.
